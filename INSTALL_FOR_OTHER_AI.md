# Как подключить skill в ChatGPT, Claude и другие ИИ

Эта инструкция написана для обычного пользователя. Она объясняет, как использовать репозиторий `skills-kadastr-conclusion` не только в Codex, но и в других ИИ-сервисах.

Важно: в разных ИИ это может называться по-разному: `skill`, `project`, `custom GPT`, `knowledge`, `instructions`, `system prompt`, `files`. Смысл один: нужно дать ИИ правила работы из `SKILL.md` и справочные файлы из папки `references`.

## Что нужно скачать

1. Откройте GitHub-репозиторий со skill.
2. Нажмите `Code` -> `Download ZIP`.
3. Распакуйте архив на компьютере.
4. Убедитесь, что внутри есть файлы:

```text
SKILL.md
README.md
references/
  document-structure.md
  public-data-lookup.md
  questions.md
  templates.md
  xml-workflow.md
```

## Главный принцип подключения

Для любого ИИ нужно сделать две вещи:

1. Добавить инструкцию поведения.
2. Добавить справочные файлы.

Коротко:

- `SKILL.md` - это главная инструкция для ИИ.
- `references/*.md` - это база знаний, которую ИИ должен использовать при работе.

Если ИИ не поддерживает загрузку файлов, откройте `SKILL.md` и нужные файлы из `references`, скопируйте их текст и вставьте в начало чата.

## Как подключить в ChatGPT через Project

Этот способ удобен, если вы регулярно создаете заключения кадастрового инженера.

По официальной справке OpenAI, Projects позволяют хранить чаты, файлы и пользовательские инструкции в одном рабочем пространстве. Project instructions действуют внутри проекта.

Шаги:

1. Откройте ChatGPT.
2. Создайте новый Project.
3. Назовите проект, например:

```text
Заключения кадастрового инженера
```

4. Откройте файл `SKILL.md` на компьютере.
5. Скопируйте весь текст из `SKILL.md`.
6. В настройках проекта найдите поле инструкций проекта.
7. Вставьте туда текст из `SKILL.md`.
8. Загрузите в проект файлы из папки `references`:

```text
document-structure.md
public-data-lookup.md
questions.md
templates.md
xml-workflow.md
```

9. Сохраните настройки проекта.
10. Начните новый чат внутри этого проекта.

Проверочный запрос:

```text
Разбери XML межевого плана по правилам проекта. Сначала задай вопросы по недостающим данным, не создавай итоговый TXT до моих ответов.
```

## Как подключить в ChatGPT через Custom GPT

Этот способ удобен, если вы хотите сделать отдельного помощника, которого можно открыть по ссылке или использовать постоянно.

По официальной справке OpenAI, Custom GPT может содержать instructions, knowledge files и выбранные capabilities.

Шаги:

1. Откройте ChatGPT.
2. Перейдите в раздел создания GPT.
3. Создайте новый GPT.
4. В поле `Instructions` вставьте весь текст из `SKILL.md`.
5. В раздел `Knowledge` загрузите файлы:

```text
references/document-structure.md
references/public-data-lookup.md
references/questions.md
references/templates.md
references/xml-workflow.md
```

6. Включите возможность работы с файлами, если такая настройка доступна.
7. Если нужно искать сведения в интернете, включите web search, если он доступен в вашей версии ChatGPT.
8. Назовите GPT, например:

```text
ЗКИ по XML
```

9. В описании можно написать:

```text
Помогает разбирать XML межевых и технических планов, задавать вопросы по недостающим данным и создавать TXT-заключения кадастрового инженера.
```

10. Сохраните GPT.

Проверочный запрос:

```text
Я приложу XML. Используй свои инструкции: сначала извлеки данные, затем задай вопросы, а итоговый файл создай только после моих ответов.
```

## Как использовать в обычном чате ChatGPT без Project и без Custom GPT

Этот способ подойдет, если нет возможности создавать Projects или GPT.

Шаги:

1. Откройте новый чат.
2. Откройте файл `SKILL.md`.
3. Скопируйте его текст и вставьте в чат с фразой:

```text
Используй следующую инструкцию как обязательные правила работы:
[вставьте текст SKILL.md]
```

4. Затем загрузите или вставьте содержимое файлов из `references`.
5. Напишите:

```text
Теперь работай по этим правилам. Я приложу XML межевого или технического плана.
```

Минус этого способа: в новом чате инструкции придется добавлять заново.

## Как подключить в Claude через Project

По официальной справке Anthropic, Claude Projects доступны на платных планах. В проект можно добавить project instructions и project knowledge.

Шаги:

1. Откройте Claude.
2. Перейдите в раздел `Projects`.
3. Нажмите `New Project`.
4. Назовите проект, например:

```text
Кадастровые заключения
```

5. Откройте `SKILL.md`.
6. Скопируйте весь текст.
7. В проекте нажмите `Set project instructions`.
8. Вставьте текст из `SKILL.md`.
9. Сохраните инструкции.
10. В project knowledge загрузите файлы из папки `references`:

```text
document-structure.md
public-data-lookup.md
questions.md
templates.md
xml-workflow.md
```

11. Начните чат внутри проекта.

Проверочный запрос:

```text
Разбери приложенный XML по инструкциям проекта. Не создавай итоговый TXT, пока не задашь вопросы и не получишь ответы.
```

## Как использовать в Claude без Project

1. Откройте новый чат Claude.
2. Прикрепите файлы:

```text
SKILL.md
references/document-structure.md
references/public-data-lookup.md
references/questions.md
references/templates.md
references/xml-workflow.md
```

3. Напишите:

```text
Используй файл SKILL.md как главную инструкцию, а файлы references как справочники. Работай строго по ним.
```

4. Затем прикрепите XML и задайте задачу.

Минус: в новом чате файлы и инструкцию нужно прикреплять снова.

## Как подключить в других ИИ

Если сервис поддерживает `Projects`, `Knowledge Base`, `Custom instructions`, `Assistants`, `Agents` или загрузку файлов, используйте универсальную схему:

1. Создайте отдельного помощника/проект.
2. В поле системной инструкции вставьте текст `SKILL.md`.
3. В базу знаний загрузите все файлы из `references`.
4. Включите работу с файлами.
5. Если требуется самостоятельный поиск ПЗЗ/НСПД/Роскадастра, включите web search или браузер, если сервис это поддерживает.
6. Проверьте помощника тестовым XML.

Если сервис не поддерживает проекты или базу знаний:

1. Вставьте `SKILL.md` в начало чата.
2. Вставьте нужные reference-файлы.
3. Прикрепите XML.
4. Попросите ИИ работать строго по этим правилам.

## Как правильно пользоваться skill

Типовой рабочий процесс:

1. Работник прикладывает XML.
2. ИИ разбирает XML.
3. ИИ определяет, какие сведения есть.
4. ИИ задает вопросы по недостающим данным.
5. Работник отвечает.
6. ИИ создает итоговый `.txt`.

Итоговый `.txt` должен содержать только текст заключения кадастрового инженера.

## Пример первого сообщения для работника

```text
Используй cadastral-conclusions.

Я прикладываю XML межевого/технического плана.

Сначала:
1. разбери XML;
2. определи тип работ;
3. найди недостающие сведения;
4. задай мне вопросы.

Не создавай итоговый TXT, пока я не отвечу на вопросы.

После моих ответов создай TXT-файл с названием: [укажите имя файла].txt
В итоговом TXT должно быть только заключение кадастрового инженера.
```

## Что нельзя делать ИИ

Проверьте, что ИИ не нарушает эти правила:

- не вставляет вопросы в итоговый TXT;
- не пишет `Из XML получено`;
- не пишет `по сведениям XML`;
- не делает служебный раздел `Требуется уточнить`;
- не придумывает данные;
- не указывает геодезическую основу;
- не использует неофициальные источники как доказательство;
- не создает `.docx`, если нужен рабочий `.txt`;
- не создает файл до ответов на вопросы.

Если ИИ нарушил правила, напишите:

```text
Переделай строго по SKILL.md. Итоговый TXT должен содержать только заключение, без вопросов, без ссылок на XML и без служебных разделов.
```

## Обновление skill

Когда в GitHub появится новая версия:

1. Скачайте новый ZIP или выполните `git pull`.
2. Замените старые файлы `SKILL.md` и `references`.
3. В ChatGPT Project / Custom GPT / Claude Project обновите инструкции и загруженные файлы.
4. Запустите короткий тест на одном XML.
